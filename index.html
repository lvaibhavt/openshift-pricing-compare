Assumptions

  • OCI: BYOM — you pay OCI compute + Block Volume, and bring your own Red Hat OpenShift subscription. 1 OCPU = 2 vCPU. Flex shapes priced per OCPU‑hr + per GB‑hr.
  • AWS ROSA (HCP): control plane hosted by Red Hat/AWS — $0.25/cluster‑hr, no master EC2. Workers pay EC2 + ROSA fee per 4 vCPU‑hr. Infra nodes pay EC2 only.
  • Azure ARO: 3 masters run as customer VMs (no OpenShift fee). Workers pay VM + ARO fee. Bare metal not offered.
  • Google OSD (CCS): masters + infra on customer GCE VMs; workers pay VM + OSD fee. Bare metal not offered.
  • IBM ROKS: masters managed by IBM at no charge; every worker/infra node pays VPC VM + OCP license. Bare metal available (Classic).
  • Other clouds get the same vCPU/RAM as OCI (OCPU × 2). Storage is mapped to the closest performance tier. Data egress, load balancers, support plans and discounts (reserved / commit) are excluded.
  • Prices are indicative list prices captured for planning; always verify with each provider's calculator.
